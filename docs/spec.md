# Minecraft実況動画編集 自動化ツール 設計書

## 1. システム概要
本システムは、Minecraftのプレイ動画（複数可）と見どころのメモを入力とし、LLMによるセリフ自動生成を経て、ゆっくりムービーメーカー4 (YMM4) のプロジェクトファイル（`.ymmp`）を直接自動生成するツールである。
`samples/` 配下の既存 `.ymmp` ファイルを構造リファレンスとして参照し、キャラクター設定やタイムライン（動画クリップ、音声アイテム）を配置する。

## 2. アプリケーションアーキテクチャ

### 2.1. UI・設定層 (Streamlit)
* **設定管理**:
  * 利用するLLMプロバイダ（OpenRouter / Gemini等）の選択とAPIキー設定。
  * 編集フレームレート設定（例: 30fps または 60fps）。
  * YMM4キャラクター設定ファイルのパス指定。
* **入力フォーム**:
  * キャラクターの性格付け・セリフ生成用プロンプト。
  * 動画ごとの入力ブロックを動的に追加できるUI。
  * 各動画ブロック内で「動画ファイルの指定」と、**構造化されたハイライト入力（`st.data_editor` 利用、「開始時間」「終了時間」「出来事」の列を持つ表形式）** を提供する。

### 2.2. LLM解析・生成層
* 構造化された入力メモとプロンプトをもとにLLM APIを呼び出し、セリフデータおよび時間アラインメント用メタデータを生成。
* 出力JSON仕様:
  * パス sample/sample_project.ymmp に実際に動画をYMM4で作成したときのymmpファイルを配置しているので、こちらを構造解析してください。

### 2.3. 中間データモデル層 (IR: Intermediate Representation)
* YMM4仕様に依存しない抽象データ構造、およびキャラクター設定のロード。
* Project: タイムライン全体のコンテナ（fps、解像度等保持）。
* VideoItem: 動画パス、開始時間、素材使用区間。
* VoiceItem: キャラクター名、セリフ、開始時間、推定尺。
* キャラクター設定のロード: YMM4のキャラクター設定やデフォルトプロパティを保持。

### 2.4. エクスポート層 (Export Layer)
* ymmp_exporter.py:
  * samples/ 配下の参考用 .ymmp ファイル（またはスキーマ構造）をベースに、IRで構築した映像クリップ・音声/セリフアイテムを埋め込み、有効な .ymmp（JSON）を出力する。

## 3. 開発フェーズ
* Phase 1: IRモデルの定義、samples/ の参考 .ymmp 読み込み／構造解析、ハードコードしたIRから最小構成の .ymmp を生成するコアエンジンの実装。
* Phase 2: StreamlitによるUI構築（構造化データ入力フォーム含む）とLLM API連携の実装。
* Phase 3: 複数ファイル対応のIR構築・タイムライン/尺計算ロジックの完成と、全体パイプラインの結合。

## 4. 技術スタック
* 言語: Python 3.10+
* UIフレームワーク: Streamlit
* LLM API: openai / google-generativeai 等
