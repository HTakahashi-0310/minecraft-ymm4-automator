# Minecraft実況動画編集 自動化ツール 設計書

## 1. システム概要
本システムは、Minecraftのプレイ動画（複数可）と見どころのメモを入力とし、LLMによるセリフ自動生成を経て、「ゆっくりムービーメーカー4 (YMM4)」のプロジェクトファイル（`.ymmp`）を自動生成するツールである。
YMM4の既存のキャラクター設定（`Characters.json`等）を読み込み、音声速度や字幕設定を反映したプロジェクトファイルを生成する。将来的な機能拡張（BGM追加等）を見据え、中間に抽象化したデータモデル（IR）を挟む設計とする。

## 2. アプリケーションアーキテクチャ

### 2.1. UI・設定層 (Streamlit)
*   **設定管理**: 
    *   利用するLLMプロバイダ（OpenRouter / Gemini等）の選択とAPIキー設定（環境変数またはセキュアなローカル保存）。
    *   YMM4キャラクター設定ファイルのパス指定（またはアップロード）。
*   **入力フォーム**:
    *   キャラクターの性格付け（プロンプト）。
    *   動画ごとの入力ブロックを動的に追加できるUI。
    *   各動画ブロック内で「動画ファイルの指定」と、**構造化されたハイライト入力（`st.data_editor` 等を利用し、「開始時間」「終了時間」「出来事」の列を持つ表形式での入力）** を提供する。

### 2.2. LLM解析・生成層
*   構造化された入力メモとプロンプトをもとにLLM APIを呼び出し、セリフデータを生成。
*   出力JSON仕様:
    ```json
    {
      "scenes": [
        {
          "startTime": "12:00",
          "endTime": "14:30",
          "script": [
            { "character": "ずんだもん", "text": "AE2の自動クラフト設定ができたのだ！" }
          ]
        }
      ]
    }
    ```

### 2.3. 中間データモデル層 (IR: Intermediate Representation)
YMM4の仕様に依存しない抽象データ構造。
*   `Project`: タイムライン全体のコンテナ。
*   `Track`: `MediaItem`のリスト。
*   `VideoItem`: 動画パス、開始時間、素材使用区間。
*   `VoiceItem`: キャラクター名、セリフ、開始時間。
*   **キャラクター設定のロード**: UIから渡されたYMM4の設定JSONをパースし、指定されたキャラクター（例: ずんだもん）の速度、音量、フォント等のデフォルトプロパティを保持する。

### 2.4. エクスポート層 (Export Layer)
構築されたIRを、YMM4が読み込み可能な `.ymmp` 形式にシリアライズして出力。
出力の際、IRで保持している「キャラクター設定」を `VoiceItem` などの対応するプロパティに適用してJSONを生成する。

## 3. 開発フェーズ
*   **Phase 1**: IRモデルの定義、YMM4キャラクター設定JSONの読み込みモック作成、およびハードコードしたIRから最小構成の `.ymmp` を生成するコアエンジンの実装。
*   **Phase 2**: StreamlitによるUI構築（構造化データ入力フォーム含む）とLLM API連携の実装。
*   **Phase 3**: 複数ファイル対応のIR構築・タイムライン計算ロジックの完成と、全体パイプラインの結合。

## 4. 技術スタック
*   **言語**: Python 3.10+
*   **UIフレームワーク**: Streamlit
*   **LLM API**: openai / google-generativeai 等
